# マークダウン記法メモ

## 見出し

```
# 見出し1
## 見出し2
### 見出し3
#### 見出し4
##### 見出し5
###### 見出し6
```

## テキスト装飾

### 強調

```
**太字** または __太字__
*イタリック* または _イタリック_
***太字イタリック*** または ___太字イタリック___
~~打消し線~~
```

**太字**、*イタリック*、***太字イタリック***、~~打消し線~~

### インラインコード

```
`インラインコード`
```

`インラインコード`

## リスト

### 順序なしリスト

```
- 項目1
- 項目2
  - 項目2-1
  - 項目2-2
- 項目3
```

### 順序付きリスト

```
1. 項目1
2. 項目2
3. 項目3
```

### チェックリスト

```
- [x] 完了したタスク
- [ ] 未完了のタスク
- [ ] 別のタスク
```

## コードブロック

### インラインコード

`` `code` ``

### コードブロック

````
```python
def hello():
    print("Hello, World!")
```

```javascript
console.log("Hello, World!");
```

```html
<div>Hello, World!</div>
```
````

## リンク

### テキストリンク

```
[リンク表示テキスト](https://example.com)
```

[例（GitHub）](https://github.com)

### 自動リンク

```
<https://example.com>
<user@example.com>
```

### ファイルリンク（VSCode）

```
[ファイル](./path/to/file.md)
[行指定](./path/to/file.md#L10)
[範囲指定](./path/to/file.md#L10-L20)
```

## 画像

```
![代替テキスト](./path/to/image.png)
![代替テキスト](https://example.com/image.png)
```


## 数式（LaTeX）

### インライン数式

```
$E = mc^2$
```

### ブロック数式

```
$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$
```

## 特殊要素

### コメント

```
<!-- これはコメント（表示されません） -->
```

### 改行

文末に空白2つ以上を入れるか、`<br>` タグを使用：

```
行の終わり  
次の行

または

行の終わり<br>
次の行
```

### エスケープ

```
\*アスタリスク\*
\[括弧\]
```

## まとめ

| 要素 | 記法 | 例 |
|------|------|-----|
| 見出し | `# テキスト` | # 見出し1 |
| 太字 | `**テキスト**` | **太字** |
| イタリック | `*テキスト*` | *イタリック* |
| リスト | `- 項目` | - 項目 |
| コード | `` `code` `` | `code` |
| リンク | `[テキスト](URL)` | [リンク](https://example.com) |
| 画像 | `![alt](画像URL)` | ![画像](https://example.com/image.png) |
| 引用 | `> テキスト` | > 引用 |
| テーブル | \| ヘッダー \| | 表形式 |
