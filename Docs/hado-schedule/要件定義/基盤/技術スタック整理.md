# 技術スタック整理

## 目的
Windows 上でローカル開発を行うための、Next.js と PostgreSQL を中心とした開発環境の技術スタックを整理します。

## 1. 基本構成

- サーバー OS: Windows
- フレームワーク: Next.js
- データベース: PostgreSQL
- パッケージマネージャ: npm
- リポジトリ管理: Git（推奨）

## 2. 開発環境構築手順

1. Node.js のインストール
   - Node.js 公式サイトから LTS 版をダウンロードしてインストール
   - `node -v` / `npm -v` で確認
2. PostgreSQL のインストール
   - PostgreSQL 公式サイトから Windows インストーラをダウンロードしてインストール
   - postgres ユーザーのパスワードを設定
   - ポート 5432 を利用
3. Git のインストール（推奨）
   - Git 公式サイトからインストール
4. Next.js プロジェクトの作成
   - `npx create-next-app@latest hado-schedules`
   - TypeScript、ESLint、Tailwind CSS などを必要に応じて選択
5. 必要なパッケージのインストール
   - `npm install`
   - `npm install pg dotenv`
6. 環境変数設定
   - プロジェクトルートに `.env.local` を作成
   - 例: `DATABASE_URL=postgresql://postgres:パスワード@localhost:5432/hado_schedules_dev`
7. データベース作成
   - `createdb -U postgres hado_schedules_dev`
8. 開発サーバ起動
   - `package.json` があるディレクトリで `npm run dev`

## 3. 推奨追加ツール

- Prisma（ORM / マイグレーション管理）
  - `npm install @prisma/client`
  - `npm install -D prisma`
  - `npx prisma init`
- pgAdmin（PostgreSQL 管理用 GUI）

## 4. フォルダ構成（想定）

- `Source/Next.js/hado-schedules/`
  - `package.json`
  - `app/`
  - `public/`
  - `node_modules/`
  - `.env.local`
- `Docs/hado-schedule/`
  - `技術スタック整理.md`

## 5. 今後の進め方

- アプリケーション要件の整理
- DB スキーマ設計
- ORM / マイグレーション導入
- API ルート実装
- フロントエンド UI 実装

## 6. 重要な注意点

- `npm run dev` は必ず `package.json` があるディレクトリで実行する
- PostgreSQL の接続情報は `.env.local` に正しく設定する
