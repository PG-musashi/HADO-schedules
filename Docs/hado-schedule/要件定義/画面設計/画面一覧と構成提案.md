# 画面一覧と推奨構成

- 以下に主要画面と簡潔な推奨構成を示します。

- **ログイン**: メール/パスワード、パスワード再設定リンク。
	- ログイン成功時は**権限に応じて遷移**します:
		- メンバー／チームリーダー → `マイページ`
		- 拠点スタッフ → `拠点スタッフメニュー`（例: `/mypage/staff`）
		- システム管理者 → `システム管理者ダッシュボード`
	- フロントでの表示切替に加え、必ずサーバー側でRBACチェックを行ってください。
- **メイン（拠点一覧 / ダッシュボード）**: フィルタ、左フィルタパネル、拠点カード、日付ピッカー（`マイページ`からアクセス）
- **拠点詳細（コートタイムライン）**: 上部拠点ヘッダ、左コートリスト、中央30分スイムレーン（10:00-22:00）、予約スライドパネル
- **予約作成（モーダル推奨）**: 種別選択→日時・コート→定員・チーム枠→確認
- **予約詳細**: 参加者一覧、キャンセルポリシー、編集/削除（権限制御）
- **マイページ**: プロフィール／プレースタイル／参加履歴／お気に入り
- **チームページ**: チーム概要／メンバー管理／チーム予約
- **拠点スタッフ：拠点管理**: 営業日カレンダー、営業時間、CSVインポート
- **拠点スタッフ：コート管理**: コート追加/編集、設備設定、利用不可登録（予約で行う）
- **システム管理者ダッシュボード**: 全データ管理・承認

注意点:
- タイムラインは30分刻みで仮想化レンダリングすることを推奨します。
- 予約競合はサーバー側でマイクロ秒比較を行い先勝ち判定。UIでは競合エラーを適切に表示してください。
