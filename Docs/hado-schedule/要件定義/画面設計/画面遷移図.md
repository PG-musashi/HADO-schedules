# 画面遷移図（概要）

以下は主要画面の遷移図です。必要に応じてMermaidを使って視覚化しています。

```mermaid
flowchart LR
  Login[ログイン]
  Main[メイン（拠点一覧）]
  Court[拠点詳細（コートタイムライン）]
  BookingCreate[予約作成]
  BookingDetail[予約詳細]
  MyPage[マイページ]
  Team[チームページ]
  StaffMenu[拠点スタッフメニュー]
  Admin[システム管理者]

  Login --> RoleCheck{権限/ロール}
  RoleCheck -->|メンバー/チームリーダー| MyPage
  RoleCheck -->|拠点スタッフ| StaffMenu
  RoleCheck -->|システム管理者| Admin
  MyPage --> Main
  Main --> Court
  Main --> BookingCreate
  Main --> Team
  Main --> StaffMenu
  Main --> Admin
  Court --> BookingDetail
  Court --> BookingCreate
  BookingCreate --> BookingDetail
  BookingDetail --> BookingCreate
  Team --> BookingCreate
  StaffMenu --> Court
  StaffMenu --> Admin
```

補足:
- `拠点詳細` は日付／コートを変更することでタイムラインが変わります。
- スタッフ／管理者はメニューから管理画面へ遷移できます。
- `チームページ`は権限別モード表示:
  - **メンバー**: 閲覧のみ（チーム情報・メンバー一覧・予約確認）
  - **チームリーダー**: 編集・管理（チーム情報編集・メンバー承認・予約管理・申請承認）
